Event contract

Stable evidence, replaceable models.

  • event_id, source, timestamp
  • Tracked detections and optional audio evidence
  • Deterministic decision and reason codes
  • Description state: pending, completed, failed, skipped

Runtime stack

Everything used in the demo.

  • Python 3.12 · uv · FastAPI · SQLite
  • RTX 4090 · PyTorch CUDA · FP16
  • YOLO26n · ByteTrack · AnimalCLAP · SmolVLM2
  • Local evidence · memory LRU · persistent cache index

Failure isolation

Useful even when enrichment fails.

  • Unavailable AnimalCLAP does not block video alerts
  • SmolVLM timeout cannot change decisions
  • Unsupported guidance returns insufficient evidence
  • Preview rendering runs after the detection response

Current limits

What the demo does not claim.

  • No exact distance, speed, or collision probability
  • No confirmed species from one-class driver detection
  • No authentication, multi-user authorization, or live wearables
  • Local SQLite logs are not consent-authorized research data
