# Hiker compatibility route

The hiker experience now lives in the main WildGuard page at
`/web/#demonstration`. This directory remains as a compatibility redirect so
older links continue to reach the working AnimalCLAP audio demonstration.

Do not add a second hiker implementation here. Add hiker-facing audio states,
phone/watch presentation, and encounter UX to `apps/web` so there is one source
of truth.
